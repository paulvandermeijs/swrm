# swrm MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Rust desktop app inspired by Superset — a window with a left sidebar (workspace switcher), right sidebar (git diff for the current workspace), and a central tabbed area that hosts working terminal sessions per workspace.

**Architecture:** Single-process Rust GUI using `gpui` (Zed's UI toolkit) and `gpui-component`'s `DockArea` for the three-pane layout. Workspaces are git worktrees, created/listed via `gix`. The right sidebar reads `git status` via `gix::status` against the active workspace's worktree. Terminal tabs combine `portable-pty` (spawn a shell, ferry bytes) with `libghostty-vt` (terminal state machine), rendered cell-by-cell into a custom `gpui` element. The workspace list persists to a JSON file in the platform config directory; everything else is in-memory for v1.

**Tech Stack:**

- `gpui` (git, pinned to a commit) — windowing, rendering, input, async executor
- `gpui-component` v0.5.x (git, `longbridge/gpui-component`) — `DockArea`, sidebars, tabs, buttons, lists
- `gix` 0.83.x (crates.io) — open repository, list worktrees, create worktree, `status`
- `libghostty-vt` (git, `Uzaaft/libghostty-rs`) — VT state machine, key encoding (requires Zig 0.15.x on PATH; user has confirmed)
- `portable-pty` 0.9.x (crates.io) — pseudo-terminal + shell spawn
- `serde` / `serde_json` — workspace list persistence
- `dirs` 6.x — platform config dir
- `anyhow` — error glue
- `tracing` + `tracing-subscriber` — logging

**Out of scope for this plan (deferred):** PR linking, agent management, multi-pane splits inside a terminal tab, per-tab session persistence, themes beyond gpui-component default, keyboard shortcut customization.

```
  vt_smoke.rs                               # feed bytes, assert snapshot cells
```

**Responsibility split:**

- `app_state.rs` is the single source of truth for which workspace is active and which sidebars are visible. Panels read from it.
- `workspace/store.rs` owns the list and persistence side-effects.
- `terminal/` is internally layered: `pty` and `vt` know nothing about gpui; `render` and `input` bridge them to gpui.
- `git/` is stateless — every call takes a repo path.

`AppState` is a gpui `Entity` (a long-lived observable model). Panels subscribe to it.

- [x] **Step 1: Create `src/app_state.rs`**

```rust
use gpui::{Context, EventEmitter};
use std::path::PathBuf;

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum AppEvent {
    ActiveWorkspaceChanged,
    SidebarToggled,
}

pub struct AppState {
    pub active_workspace: Option<PathBuf>,
    pub left_sidebar_visible: bool,
    pub right_sidebar_visible: bool,
}

impl AppState {
    pub fn new() -> Self {
        Self {
            active_workspace: None,
            left_sidebar_visible: true,
            right_sidebar_visible: true,
        }
    }

    pub fn set_active_workspace(&mut self, path: Option<PathBuf>, cx: &mut Context<Self>) {
        if self.active_workspace != path {
            self.active_workspace = path;
            cx.emit(AppEvent::ActiveWorkspaceChanged);
            cx.notify();
        }
    }

    pub fn toggle_left_sidebar(&mut self, cx: &mut Context<Self>) {
        self.left_sidebar_visible = !self.left_sidebar_visible;
        cx.emit(AppEvent::SidebarToggled);
        cx.notify();
    }

    pub fn toggle_right_sidebar(&mut self, cx: &mut Context<Self>) {
        self.right_sidebar_visible = !self.right_sidebar_visible;
        cx.emit(AppEvent::SidebarToggled);
        cx.notify();
    }
}

impl EventEmitter<AppEvent> for AppState {}
```

```rust
use crate::app_state::AppState;
use gpui::{App, Context, Entity, Window};
use gpui_component::dock::{DockArea, DockItem, DockPlacement};
use std::sync::Arc;

pub fn build(
    state: Entity<AppState>,
    window: &mut Window,
    cx: &mut Context<DockArea>,
) -> DockArea {
    let mut area = DockArea::new("swrm-root", Some(1), window, cx);
    let weak = cx.weak_entity();

    let left = Arc::new(cx.new(|cx| LeftSidebarPanel::new(state.clone(), cx)));
    let right = Arc::new(cx.new(|cx| RightSidebarPanel::new(state.clone(), cx)));
    let center_tabs = Arc::new(cx.new(|cx| MainTabsPanel::new(state.clone(), cx)));

    area.add_panel(left, DockPlacement::Left, None, window, cx);
    area.add_panel(right, DockPlacement::Right, None, window, cx);

    let center = DockItem::tabs(vec![center_tabs], &weak, window, cx);
    area.set_center(center, window, cx);

    area
}
```

```rust
use super::Workspace;
use anyhow::{Context, Result};
use std::fs;
use std::path::{Path, PathBuf};

pub fn config_path() -> Result<PathBuf> {
    let dir = dirs::config_dir().context("no config dir on this platform")?;
    Ok(dir.join("swrm").join("workspaces.json"))
}

pub fn load_from(path: &Path) -> Result<Vec<Workspace>> {
    if !path.exists() {
        return Ok(Vec::new());
    }
    let raw = fs::read_to_string(path).with_context(|| format!("read {}", path.display()))?;
    Ok(serde_json::from_str(&raw)?)
}

pub fn save_to(path: &Path, workspaces: &[Workspace]) -> Result<()> {
    if let Some(parent) = path.parent() {
        fs::create_dir_all(parent)?;
    }
    let raw = serde_json::to_string_pretty(workspaces)?;
    fs::write(path, raw)?;
    Ok(())
}

pub fn load() -> Result<Vec<Workspace>> {
    load_from(&config_path()?)
}

pub fn save(workspaces: &[Workspace]) -> Result<()> {
    save_to(&config_path()?, workspaces)
}
```

```rust
use anyhow::{Context, Result};
use std::path::{Path, PathBuf};

pub fn validate_repo(path: &Path) -> Result<gix::Repository> {
    gix::open(path).with_context(|| format!("{} is not a git repository", path.display()))
}

pub fn current_branch(repo: &gix::Repository) -> Option<String> {
    repo.head_name().ok().flatten().map(|name| name.shorten().to_string())
}

pub fn list_worktrees(repo: &gix::Repository) -> Result<Vec<PathBuf>> {
    let mut out = Vec::new();
    out.push(repo.workdir().context("bare repo not supported")?.to_path_buf());
    for proxy in repo.worktrees()? {
        if let Ok(repo) = proxy.into_repo() {
            if let Some(dir) = repo.workdir() {
                out.push(dir.to_path_buf());
            }
        }
    }
    Ok(out)
}

pub fn create_worktree(repo: &gix::Repository, branch: &str, target_dir: &Path) -> Result<PathBuf> {
    // gix's worktree API is still maturing. If `repo.worktree_add(...)` exists by the rev
    // pinned in Cargo.toml, use it. Otherwise shell out to `git worktree add` as a
    // pragmatic fallback — same effect, no separate install required.
    let workdir = repo.workdir().context("bare repo not supported")?;
    let status = std::process::Command::new("git")
        .arg("-C")
        .arg(workdir)
        .arg("worktree")
        .arg("add")
        .arg(target_dir)
        .arg(branch)
        .status()
        .context("spawn `git worktree add`")?;
    anyhow::ensure!(status.success(), "git worktree add failed");
    Ok(target_dir.to_path_buf())
}
```

The `create_worktree` fallback uses the system `git` binary; this is a deliberate trade-off (gix's worktree-mutation surface is incomplete and we want to ship Phase 2 without blocking).

```rust
        let workspaces = persistence::load().unwrap_or_else(|err| {

            Vec::new()

        Self { workspaces }
    }

    pub fn add(&mut self, ws: Workspace, cx: &mut Context<Self>) {
        if !self.workspaces.iter().any(|w| w.path == ws.path) {
            self.workspaces.push(ws);
            self.persist();
            cx.emit(WorkspaceEvent::Changed);
            cx.notify();
        }
    }

    pub fn remove(&mut self, path: &PathBuf, cx: &mut Context<Self>) {
        self.workspaces.retain(|w| &w.path != path);
        self.persist();
        cx.emit(WorkspaceEvent::Changed);
        cx.notify();
    }

    fn persist(&self) {
        if let Err(err) = persistence::save(&self.workspaces) {
            tracing::error!(?err, "failed to persist workspaces");
        }
    }
}
```

```rust
use anyhow::Result;
use std::path::{Path, PathBuf};

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Status {
    Modified,
    Added,
    Deleted,
    Renamed,
    Untracked,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct StatusEntry {
    pub path: PathBuf,
    pub status: Status,
}

pub fn collect_status(repo_path: &Path) -> Result<Vec<StatusEntry>> {
    let repo = gix::open(repo_path)?;
    let platform = repo.status(gix::progress::Discard)?;
    let mut entries = Vec::new();
    for item in platform.into_iter([])? {
        let item = item?;
        // The exact variant names depend on the gix version. After cargo build
        // fails the first time, look at the `gix::status::Item` enum in the
        // local checkout and map each variant to one of our Status values.
        match item {
            gix::status::Item::IndexWorktree(change) => entries.push(map_index_worktree(change)),
            gix::status::Item::TreeIndex(change) => entries.push(map_tree_index(change)),
        }
    }
    Ok(entries)
}

fn map_index_worktree(change: gix::status::index_worktree::Item) -> StatusEntry {
    use gix::status::index_worktree::Item as I;
    match change {
        I::Modification { rela_path, .. } => StatusEntry {
            path: rela_path.to_path_lossy().into_owned(),
            status: Status::Modified,
        },
        I::DirectoryContents { entry, .. } => StatusEntry {
            path: entry.rela_path.to_path_lossy().into_owned(),
            status: Status::Untracked,
        },
        I::Rewrite { dirwalk_entry, .. } => StatusEntry {
            path: dirwalk_entry.rela_path.to_path_lossy().into_owned(),
            status: Status::Renamed,
        },
    }
}

fn map_tree_index(change: gix::status::tree_index::ChangeRef<'_>) -> StatusEntry {
    StatusEntry {
        path: change.location().to_path_lossy().into_owned(),
        status: Status::Added,
    }
}
```

**The exact enum and field names above are gix-version-dependent.** When `cargo check` fails, open `~/.cargo/registry/src/.../gix-0.83.*/src/status/` (or the docs page for the pinned version) and adapt. The contract that callers see — `Vec<StatusEntry>` — does not change.

### Task 17: PTY session

**Files:**

- Modify: `src/terminal/pty.rs`

A `PtySession` spawns a login shell in a given `cwd`, returns a reader thread that drops bytes onto a `std::sync::mpsc` channel, and a writer handle.

- [x] **Step 1: Write `src/terminal/pty.rs`**

```rust
use anyhow::{Context, Result};
use portable_pty::{Child, CommandBuilder, MasterPty, PtySize, native_pty_system};
use std::io::{Read, Write};
use std::path::Path;
use std::sync::mpsc::{Receiver, Sender, channel};
use std::thread::JoinHandle;

pub struct PtySession {
    pub master: Box<dyn MasterPty + Send>,
    pub child: Box<dyn Child + Send + Sync>,
    pub output_rx: Receiver<Vec<u8>>,
    pub writer: Box<dyn Write + Send>,
    _reader_thread: JoinHandle<()>,
}

impl PtySession {
    pub fn spawn(cwd: &Path, cols: u16, rows: u16) -> Result<Self> {
        let pair = native_pty_system().openpty(PtySize {
            cols,
            rows,
            pixel_width: 0,
            pixel_height: 0,
        })?;
        let shell = std::env::var("SHELL").unwrap_or_else(|_| "/bin/sh".into());
        let mut cmd = CommandBuilder::new(shell);
        cmd.cwd(cwd);
        let child = pair.slave.spawn_command(cmd).context("spawn shell")?;
        drop(pair.slave);

        let mut reader = pair.master.try_clone_reader()?;
        let writer = pair.master.take_writer()?;

        let (tx, output_rx): (Sender<Vec<u8>>, _) = channel();
        let _reader_thread = std::thread::spawn(move || {
            let mut buf = [0u8; 4096];
            loop {
                match reader.read(&mut buf) {
                    Ok(0) => break,
                    Ok(n) => {
                        if tx.send(buf[..n].to_vec()).is_err() {
                            break;
                        }
                    }
                    Err(_) => break,
                }
            }
        });

        Ok(Self {
            master: pair.master,
            child,
            output_rx,
            writer,
            _reader_thread,
        })
    }

    pub fn resize(&mut self, cols: u16, rows: u16) -> Result<()> {
        self.master.resize(PtySize {
            cols,
            rows,
            pixel_width: 0,
            pixel_height: 0,
        })?;
        Ok(())
    }

    pub fn write_input(&mut self, bytes: &[u8]) -> Result<()> {
        self.writer.write_all(bytes)?;
        Ok(())
    }
}
```

### Task 18: `Terminal` composite

**Files:**

- Modify: `src/terminal/mod.rs`

A `Terminal` owns a `PtySession` and a `VtWrapper`. A `tick(&mut self)` drains pending bytes from the PTY channel into the VT. A `write_input(bytes)` forwards to the PTY. A `snapshot()` proxies to the VT.

```rust
use anyhow::Result;
use std::path::Path;

pub struct Terminal {
    pub pty: pty::PtySession,
    pub vt: VtWrapper,
}

impl Terminal {
    pub fn spawn(cwd: &Path, cols: u16, rows: u16) -> Result<Self> {
        let pty = pty::PtySession::spawn(cwd, cols, rows)?;
        let vt = VtWrapper::new(cols, rows)?;
        Ok(Self { pty, vt })
    }

    /// Drains any pending PTY output into the VT. Returns whether anything changed.
    pub fn tick(&mut self) -> bool {
        let mut changed = false;
        while let Ok(chunk) = self.pty.output_rx.try_recv() {
            self.vt.feed(&chunk);
            changed = true;
        }
        changed
    }

    pub fn write_input(&mut self, bytes: &[u8]) -> Result<()> {
        self.pty.write_input(bytes)
    }

    pub fn resize(&mut self, cols: u16, rows: u16) -> Result<()> {
        self.pty.resize(cols, rows)?;
        self.vt.resize(cols, rows)?;
        Ok(())
    }

    pub fn snapshot(&mut self) -> Result<Snapshot> {
        self.vt.snapshot()
    }
}
```

```rust
use gpui::KeyDownEvent;

pub fn encode(event: &KeyDownEvent) -> Option<Vec<u8>> {
    let keystroke = &event.keystroke;
    if keystroke.modifiers.control {
        if let Some(ch) = keystroke.key.chars().next() {
            if ch.is_ascii_alphabetic() {
                let lower = ch.to_ascii_lowercase() as u8;
                return Some(vec![lower - b'a' + 1]);
            }
        }
    }
    match keystroke.key.as_str() {
        "enter" => Some(b"\r".to_vec()),
        "backspace" => Some(b"\x7f".to_vec()),
        "tab" => Some(b"\t".to_vec()),
        "escape" => Some(b"\x1b".to_vec()),
        "left" => Some(b"\x1b[D".to_vec()),
        "right" => Some(b"\x1b[C".to_vec()),
        "up" => Some(b"\x1b[A".to_vec()),
        "down" => Some(b"\x1b[B".to_vec()),
        _ => keystroke.ime_key.clone().or_else(|| {
            let k = &keystroke.key;
            if k.chars().count() == 1 { Some(k.clone()) } else { None }
        })
        .map(|s| s.into_bytes()),
    }
}
```

```rust
impl TerminalTab {
    pub fn new(label: String, cwd: PathBuf, cx: &mut Context<Self>) -> anyhow::Result<Self> {
        let terminal = Terminal::spawn(&cwd, 80, 24)?;
        let focus = cx.focus_handle();
        cx.spawn(async move |this, cx| {
```

```rust
fn new_worktree(&mut self, window: &mut Window, cx: &mut Context<Self>) {
    let Some(active) = self.state.read(cx).active_workspace.clone() else { return };
    let state = self.state.clone();
    let branch_prompt = cx.prompt(gpui::PromptLevel::Info, "Branch name", None, &["Create", "Cancel"]);
    let dir_task = cx.prompt_for_paths(gpui::PathPromptOptions {
        files: false,
        directories: true,
        multiple: false,
    });
    cx.spawn_in(window, async move |this, cx| {
        let _ = branch_prompt.await; // currently no text-prompt API — use a hard-coded branch for v1.
        let Some(Ok(Some(paths))) = dir_task.await.ok() else { return };
        let Some(target) = paths.into_iter().next() else { return };
        let _ = this.update(cx, |this, cx| {
            let repo = match workspace::validate_repo(&active) {
                Ok(r) => r,
                Err(_) => return,
            };
            // Branch name plumbing: prompt UI is a TODO — for v1, derive from target dir name.
            let branch = target.file_name().map(|s| s.to_string_lossy().to_string()).unwrap_or_else(|| "swrm-wt".into());
            if let Err(err) = workspace::create_worktree(&repo, &branch, &target) {
                tracing::warn!(?err, "create_worktree failed");
                return;
            }
            this.handle_picked(target, cx);
        });
    })
    .detach();
}
```

gpui doesn't expose a generic text-input prompt out of the box, so for v1 the branch name is derived from the target directory name (`~/repos/foo-wt/feature-x` → branch `feature-x`). A proper text-prompt modal is a follow-up.

## Notes for the executing engineer

- **The two biggest sources of build pain are `gpui` and `libghostty-vt`.** Both are git deps that pull large source trees and require live builds. The first `cargo build` will take a long time. If `gpui` fails, pin a recent SHA from `zed-industries/zed`'s `main` branch instead of `branch = "main"` — Zed's main is occasionally broken.
- **Adapt enum/method names when the compiler says they're wrong.** Specifically `gix::status::Item` variants, `gpui_component::dock::Panel` trait methods, `libghostty_vt::RenderState` row/cell iterator names. The plan picks names that are consistent with the published docs at time of writing; minor drifts are expected and the fix is mechanical.
- **Don't add features the plan didn't ask for.** Specifically: don't add ANSI color rendering, don't add syntax highlighting, don't add a settings UI, don't add multi-pane terminal splits. Each of those is its own plan.
- **Persistence is workspace-list-only by user choice.** Tabs and selected workspace are deliberately not saved.
